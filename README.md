# 🤖 Autonomous Mobile Robot (AMR) | NVIDIA Isaac Sim + ROS 2

## 📌 Overview

This project focuses on developing and simulating an **Autonomous Mobile Robot (AMR)** using NVIDIA Isaac Sim and ROS 2. The simulation explores autonomous robot navigation, movement, path planning, and obstacle avoidance within a physics based virtual environment.

The goal is to understand how autonomous mobile robots perceive their surroundings, navigate through environments, and perform tasks without continuous human intervention.

## 🚀 Technologies Used

- **NVIDIA Isaac Sim** – Physics-based robotics simulation.
- **ROS 2** – Robot communication, control, and navigation framework.
- **USD (Universal Scene Description)** – 3D simulation environment.
- **Python** – Robotics scripting and automation.

## ⚙️ Key Features

- Autonomous mobile robot simulation.
- ROS 2 integration for robot communication.
- Mobile robot movement and control.
- Exploration of autonomous navigation.
- Path planning and trajectory execution.
- Obstacle avoidance concepts.
- Physics-based simulation environment.

## 🎯 Project Objectives

- Understand autonomous mobile robotics.
- Explore ROS 2-based robot control.
- Implement navigation and movement workflows.
- Study path planning and obstacle avoidance.
- Gain practical experience with NVIDIA Isaac Sim.
